# Ledge

Полка для перетаскивания на macOS. Тащишь файл к левому краю экрана — выезжает
стеклянная карточка, кидаешь туда что угодно, потом вытаскиваешь в нужное место.
Аналог Yoink, только свой и бесплатный.

## Что умеет

- **Появляется по касанию грани экрана** курсором — хоть просто мышкой, хоть
  во время перетаскивания. Больше ничего на экране не висит.
- **Переставляется куда угодно**: тянешь за полоску сверху, полка липнет к
  ближайшей грани экрана (левой, правой, верхней, нижней) с тем же отступом.
  Куда положил — оттуда и вызывается. Если рука по привычке пошла в старое
  место, из-за нужной грани высунется только краешек полки и качнётся —
  «я тут». Пойдёшь к нему — развернётся целиком.
- **Принимает всё**: файлы и папки из Finder, картинки с сайтов, текст, ссылки.
  Не-файлы сохраняются в свою папку: картинка → `.png`, ссылка → `.webloc`,
  текст → `.txt`.
- **Настоящие превью** файлов через QuickLook. Клик по файлу — быстрое превью
  рядом с полкой, как пробел в Finder. Повторный клик закрывает.
- **Вытаскивание**: тяни строку — уедет один файл; тяни заголовок «Полка» —
  уедут все разом. Двойной клик открывает файл.
- **Оставлять после перетаскивания** — переключатель в меню, включён по
  умолчанию. Вещь остаётся на полке, даже когда её утащили наружу: одну и ту же
  картинку можно разложить в несколько мест подряд. Выключишь — полка снова
  работает как полка: взял и унёс. Исключение одно: если принимающая программа
  забрала файл переездом, а не копией, строка убирается в любом случае —
  оригинал уехал, и показывать было бы нечего.
- **Скриншоты и записи экрана** (⌘⇧3 / ⌘⇧4 / ⌘⇧5) падают сразу на полку,
  а не на рабочий стол. Плавающая превьюшка в углу выключается, чтобы снимок
  появлялся мгновенно, а не через несколько секунд.
- **Буфер обмена**: всё скопированное тоже попадает на полку — текст, картинки,
  SVG, файлы, ссылки, видео. Скопированный SVG-код сохраняется как `.svg`,
  а не как текст. Содержимое из менеджеров паролей игнорируется.
- Оформление — родное для macOS 26: Liquid Glass, светлая и тёмная тема,
  системный акцентный цвет.

## Расширенный режим

Переключатель в меню строки меню. Полка остаётся полкой — узкой карточкой у
грани, куда таскают файлы. Расширенный режим добавляет ей вторую ипостась:
широкую **ленту карточек** вдоль той же грани, с историей буфера, поиском и
стопками. Вызывается ⌘⇧V, кнопкой разворота в шапке полки или пунктом меню.

- **Карточки вместо строк.** У картинки — сама картинка, у текста — его первые
  строки, у ссылки — адрес. Внизу карточки мера вещи (`442 знака`,
  `2400 × 2400`, `1,2 МБ`) и когда она появилась. В шапке — из какой программы
  приехало, со значком этой программы.
- **Стопки.** Именованная кучка вещей со своим цветом. Цвет виден **корешком**
  на левом краю карточки — вещи стоят на полке корешками наружу. Брось карточку
  на корешок стопки — она туда ляжет; можно бросить и файл прямо из Finder.
  Из стопки вещь не выдавливается историей: лежит, пока сам не уберёшь.
- **Поиск** по имени, содержимому, виду и программе-источнику — просто начни
  печатать. Фильтр по виду (текст, картинки, ссылки, файлы) — в меню «…».
- **Вставка туда, где работал.** ↩ кладёт вещь в буфер и жмёт ⌘V за тебя в той
  программе, что была впереди. Для этого macOS попросит доступ к
  «Универсальному доступу» — без него вещь просто ляжет в буфер.
- **История длиннее.** В обычном режиме буфер хранится 25 записями, в
  расширенном — 200. Принесённое руками и разложенное по стопкам не в счёт.

Куда прижата полка — там и лента. У левой и правой грани это колонка в два ряда,
которая растёт по содержимому; у верхней и нижней — лента во всю ширину.

### Клавиши

| Клавиша | Что делает |
|---|---|
| ⌘⇧V | открыть и закрыть ленту |
| ← → ↑ ↓ | ходить по карточкам |
| ⇧ + стрелки, ⌘-клик | взять несколько |
| ↩ | вставить туда, где работал |
| ⇧↩ | вставить простым текстом |
| ⌘1 … ⌘9 | вставить карточку по номеру (номера проступают, пока держишь ⌘) |
| ⌘C | скопировать |
| Пробел | раскрыть превью |
| ⌘O | открыть файл или ссылку |
| ⌘E | разметить картинку |
| ⌫ | убрать с полки |
| ⌘F | искать |
| ⌘← ⌘→ | между стопками |
| ⌘⇧N | новая стопка |
| Esc | закрыть |

Шпаргалка живёт в меню «…» → «Клавиши».

## Разметка картинок

У картинки на полке при наведении появляется карандаш — открывается окно
разметки:

- **стрелка**, **рамка**, **карандаш** — показать, о чём речь;
- **замазка** — крупные квадраты вместо содержимого. Не размытие: пиксели
  теряются насовсем, восстановить нельзя;
- пять цветов и три толщины. Толщина считается от размера картинки, чтобы на
  большом скриншоте линия не выходила волосяной.

Клавиши: `1`–`4` — инструменты, `⌘Z` — отменить, `⌘C` — скопировать
размеченное, `⌘S` — записать поверх файла, `Esc` — закрыть.

Штрихи хранятся в координатах самой картинки, поэтому при сохранении ничего
не едет от масштаба окна. Скопированное полка обратно не подбирает — иначе
на ней сразу появлялась бы копия только что размеченного.

## Сборка

```
./build.sh
```

Получится `Ledge.app` рядом. Перетащи его в «Программы» и запусти.
Приложение живёт в строке меню (значок полки), иконки в доке нет.

## Меню в строке меню

| Пункт | Что делает |
|---|---|
| Показать полку | Открыть/закрыть вручную |
| Открыть ленту (⌘⇧V) | Расширенный режим: история, поиск, стопки |
| Вернуть полку на место | Обратно к левой грани по центру |
| Очистить | Убрать всё с полки |
| Расширенный режим | Включает ленту, ⌘⇧V и кнопку разворота на полке |
| Скриншоты — сразу на полку | Вкл/выкл перехват снимков экрана |
| Буфер обмена — на полку | Вкл/выкл перехват копирования |
| Папка снимков | Открыть, куда падают скриншоты |
| Папка хранилища | Открыть служебную папку |
| Запускать при входе | Автозапуск |
| Выйти из Ledge | Выход |

## Где что лежит

- Список полки и вложения: `~/Library/Application Support/Ledge/`
- Скриншоты: `~/Library/Application Support/Ledge/Снимки/`

Файлы из Finder полка **не копирует** — держит ссылку на оригинал. Убрал с полки
— оригинал на месте. Удаляются только те файлы, которые полка создала сама
(текст, картинки из буфера, ссылки).

История буфера ограничена 25 записями (в расширенном режиме — 200) — старые
уезжают сами, чтобы не выдавливать то, что притащили руками. Файлы из Finder и
вещи из стопок это не трогает.

Стопки: `~/Library/Application Support/Ledge/boards.json`

### Вернуть скриншоты на рабочий стол

Выключить пункт «Скриншоты — сразу на полку» в меню. Или руками:

```
defaults delete com.apple.screencapture location && defaults write com.apple.screencapture show-thumbnail -bool true && killall SystemUIServer
```

## Разрешения

При первом перетаскивании файлов из «Документов», «Рабочего стола» или
«Загрузок» macOS спросит доступ к папке — это нужно для превью. Полка ничего
никуда не отправляет и работает целиком офлайн.
